# DT cop

A bilingual, responsive company site for DT cop, a developer tools company based in Taiwan and focused on making cross-platform app development easier to approach.

## Preview locally

Open [index.html](./index.html) in a browser. The site is a single static HTML file with no build step or dependencies.

## Included

- English and Traditional Chinese language switcher
- Responsive one-page layout
- Company overview and cross-platform development approach
- Inline favicon, styles, and language-switching script

The page uses only the company details shared so far. Add confirmed product names, supported platforms, and contact information before making more specific product claims.
